# Editor Setup

This page has moved. See **[Editor Setup](./getting-started/editor-setup.md)** in
Getting Started for VS Code / Cursor, ESLint, Neovim, JetBrains and Sublime Text.

The recommended editor integration is the TypeScript language-service plugin
(`@typesugar/transformer/language-service`, configured in `tsconfig.json`), which
works in any editor that uses tsserver. The standalone `@typesugar/lsp-server` is
frozen (not under active development).
