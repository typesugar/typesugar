# Editor Setup

This page has moved. See **[Editor Setup](./getting-started/editor-setup.md)** in
Getting Started for VS Code / Cursor, Neovim, Zed, Sublime Text, Helix, Emacs, JetBrains,
ESLint and Prettier.

typesugar's editor engine is the TypeScript language-service plugin
(`@typesugar/transformer/language-service`, configured in `tsconfig.json`), which
works in any editor that uses tsserver.
